- Optimization Problems
    - First Derivative f'(x)
        - +ve $\implies$ f(x) increasing
        - -ve $\implies$ f(x) decreasing
        - 0 $\implies$ f(x) stationary/turning-point
        - 0 or undef $\implex$ Critical-Point
        - Task:
            - let f'(x) = 0 and solve ==> find turning-points ==> you can find intervals
            - Extrema
                - ----------------   left   --- f'(x) = Critical Point ----- right --
                - Relative Maxima:  f(x) ⬆️ --            ''            --  f(x) ⬇️
                - Relative Minima:  f(x) ⬇️ --            ''            --  f(x) ⬆️
    - Second Derivative f''(x)
        - +ve $\implies$ f(x) concave-up    $\implies$ relative minima [extrema][f'(x)=0]
        - -ve $\implies$ f(x) concave-down  $\implies$ relative maxima [extrema][f'(x)=0]
        - 0 $\implies$ f(x) inflection point = concavity changes
        - Task:
            - let f''(x) = 0 and solve ==> find inflection points ==> you can find intervals
